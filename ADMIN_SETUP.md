# Админ-панель AMBERIC AROMA

Панель находится по адресу `/admin/` и использует Decap CMS. Каталог хранится в `content/catalog.json`, а фотографии — в `images/`.

## Что уже сделано

- добавлена отдельная страница `/admin/`;
- добавлена форма каталога: бренд, название, описание, пол, фото, объёмы и цены;
- изменения каталога подхватываются витриной из `content/catalog.json`;
- старый `catalog.js` остаётся резервным источником, если JSON временно недоступен.

## Что нужно настроить один раз

1. Создать бесплатный сайт в Decap Turbo.
2. Привязать репозиторий `Muhamed767/Amberic-Aroma` и ветку `main`.
3. Добавить в настройках Decap Turbo адрес `https://muhamed767.github.io/Amberic-Aroma/admin/`.
4. UUID сайта уже подключён в `admin/config.yml`.
5. Пригласить пользователей в Decap Turbo. Пароли создаются ими через защищённую форму входа и не хранятся в коде.

Бесплатный тариф рассчитан на один сайт и одного пользователя. Для второго отдельного пользователя нужен либо платный слот, либо отдельная схема авторизации через GitHub-аккаунты/OAuth. Один общий пароль в код сайта добавлять нельзя: его сможет увидеть любой посетитель.
